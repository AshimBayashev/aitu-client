# Aitu здорового человека

Неофициальный клиент [Aitu](https://aitu.io) для Windows. Веб-версия долго отправляет сообщения, не даёт разложить чаты по папкам, персонализировать вид чатов, забагованная и неудобная в целом. Мой клиент оставляет обычную переписку и даёт настроить вид под себя.

ВАЖНО! Проект не связан с BTS Digital. Вход идёт в ваш собственный аккаунт через окно Passport.

Установить для Windows можно из Microsoft Store: [Aitu здорового человека](https://apps.microsoft.com/detail/9ND7DC3NGZ6F?hl=ru-ru&gl=KZ).

## Функционал

- Список чатов, история и отправка текста
- Файлы, ссылки в сообщениях и фото профилей
- Эмодзи и голосовые: запись из поля ввода и прослушивание прямо в чате
- Ответы на сообщения и карточка чата справа
- Закреплённые чаты без ограничения по количеству
- Сообщения одного человека собираются в пачку
- Галочки доставки и прочтения
- Папки в духе Telegram: «Все», «Личные», «Группы», «Каналы» и свои
- Светлая и тёмная тема, свой цвет акцента, шрифт, размер, плотность списка и фон чата
- Уведомления о новых сообщениях
- Закрытие окна прячет клиент в трей, полный выход — из меню трея

Папки, закрепления и оформление остаются на этом компьютере. Переписка подтягивается из аккаунта Aitu.

## Запуск

Нужны Windows 10 или 11, WebView2, Node.js 20 и Rust со сборкой MSVC (Visual Studio Build Tools).

```bash
npm install --legacy-peer-deps
npm run tauri dev
```

Установщик:

```bash
npm run tauri build
```

## Как устроено

Интерфейс — React и TypeScript на Vite, окно — Tauri 2. Запросы к Aitu выполняет Rust: страница в окне не может сама сходить в API с сессионной cookie.
